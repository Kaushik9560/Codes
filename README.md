# Codes

V Semester BCA — Frontend React Lab

The React section of the V Semester BCA frontend lab manual is ready in [`exp/`](exp/README.md).

- [Browse the seven programs and copy instructions](exp/README.md#programs)
- [Copyable program files](exp/programs/)

Programs 4–9 each need only their `App.jsx` copied into your own `src/App.jsx`. Program 10 also needs `StyledComponent.css` because it demonstrates external CSS. Keep your project's `src/main.jsx`.

To run all seven examples with the program selector:

```bash
cd exp
npm install
npm run dev
```

Upload the source files and keep `exp/.gitignore` so `node_modules/` and `dist/` stay out of GitHub. See the [full README](exp/README.md) for setup, expected results, and validation commands.
